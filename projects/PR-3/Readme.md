# Student Data Organizer

## Overview

Student Data Organizer is a Python console-based application that helps users manage student records. The program allows users to add, display, update, and delete student information, as well as view all subjects offered by students.

---

## Features

- Add new student records
- Display all student records
- Update student information
- Delete student records
- Display all unique subjects offered
- Menu-driven interface
- Easy to use and understand

---

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Sets
- Loops
- Match-Case Statements

---

## Student Information Stored

Each student record contains:

- Student ID
- Name
- Age
- Grade
- Date of Birth (DOB)
- Subjects

---

## Menu Options

### 1. Add Student
Allows users to enter and save a new student's details.

### 2. Display All Students
Displays all student records stored in the system.

### 3. Update Student Information
Updates the information of an existing student using the Student ID.

### 4. Delete Student
Deletes a student record using the Student ID.

### 5. Display Subjects Offered
Shows all unique subjects selected by students.

### 6. Exit
Closes the application.
