# 📊 Data Analyzer and Transformer Program

A simple Python console application that allows users to input numerical data and perform various data analysis and transformation operations using Python functions, recursion, lambda functions, sorting, and multiple return values.

---

## 🚀 Features

- ✅ Input a list of numbers
- ✅ Display dataset summary
- ✅ Calculate factorial using recursion
- ✅ Filter data using a threshold (Lambda Function)
- ✅ Sort data in ascending or descending order
- ✅ Display dataset statistics
- ✅ Menu-driven interface

---

- Python 3

## 📋 Menu Options

### 1. Input Data
Allows the user to enter multiple integer values separated by spaces.

Example:
```
10 20 30 40 50
```

---

### 2. Display Data Summary
Displays:

- Total number of elements
- Minimum value
- Maximum value
- Sum of all values
- Average of values

---

### 3. Calculate Factorial (Recursion)
Calculates the factorial of a given number using a recursive function.

Example:
```
Enter number: 5

Output:
120
```

---

### 4. Filter Data by Threshold (Lambda Function)

Displays all numbers greater than the threshold entered by the user.

Example:

Data:
```
10 20 30 40 50
```

Threshold:
```
25
```

Output:
```
30 40 50
```

---

### 5. Sort Data

Provides two sorting options:

- Ascending Order
- Descending Order

Example:

Ascending:
```
10 20 30 40 50
```

Descending:
```
50 40 30 20 10
```

---

### 6. Display Dataset Statistics

Returns and displays:

- Total
- Average
- Maximum
- Minimum

using a function that returns multiple values.

---

### 7. Exit Program

Terminates the application.
