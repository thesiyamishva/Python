# 📖 Personal Journal Manager

A simple command-line **Personal Journal Manager** built with **Python** using **Object-Oriented Programming (OOP)** and **File Handling** concepts. This application allows users to write, view, search, and delete journal entries stored in a text file.

---

## 🚀 Features

- ✍️ Add new journal entries with date and time
- 📄 View all saved journal entries
- 🔍 Search journal entries by keyword or date
- 🗑️ Delete all journal entries with confirmation
- ⚠️ Exception handling for common file errors
- 🧱 Object-Oriented Programming (OOP) implementation

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (Classes & Methods)
