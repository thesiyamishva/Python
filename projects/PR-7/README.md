# 🛠️ Multi Utility Toolkit (Python)

A menu-driven Python application that combines multiple useful utilities into one program. This project demonstrates the use of Python's built-in modules such as `datetime`, `time`, `math`, `random`, `string`, `uuid`, and `os`.

## 📌 Features

### 📅 Datetime & Time Operations
- Display current date and time
- Calculate difference between two dates
- Format dates into different styles
- Stopwatch
- Countdown timer

### ➗ Mathematical Operations
- Calculate factorial
- Compound interest calculator
- Trigonometric calculations (Sin, Cos, Tan)
- Area calculator
  - Circle
  - Rectangle
  - Triangle

### 🎲 Random Data Generation
- Generate random number
- Generate random list
- Create secure random password
- Generate 6-digit OTP

### 🆔 UUID Generator
- Generate UUID Version 1
- Generate UUID Version 4
- Generate multiple UUIDs

### 📂 File Operations
- Create file
- Read file
- Append text to file
- Delete file
- Display file information

### 🔍 Module Explorer
Explore attributes of Python modules using `dir()`:
- math
- random
- datetime
- uuid
- os
