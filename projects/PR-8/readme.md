# PR-8 NumPy Analyzer

## Description

NumPy Analyzer is a menu-driven Python application developed using NumPy.

It allows users to create and analyze NumPy arrays and perform different operations such as indexing, slicing, mathematical calculations, combining, splitting, searching, sorting, filtering, and statistical analysis.

## Features

- Create 1D, 2D, and 3D NumPy arrays
- Array indexing and slicing
- Addition, subtraction, multiplication, and division
- Dot product
- Matrix multiplication
- Combine arrays
- Split arrays
- Search values
- Sort arrays
- Filter values using conditions
- Calculate sum and mean
- Calculate median
- Calculate standard deviation
- Calculate variance
- Find minimum and maximum values
- Calculate percentiles
- Calculate correlation coefficient
- Menu-driven interface

## Requirements

- Python 3.x
- NumPy

## Installation

Install NumPy using:

```bash
pip install numpy
```

How to Run

Run the following command in the terminal:

python Analyzer.py
Main Menu

The program provides the following options:

Create a Numpy Array
Array Indexing and Slicing
Perform Mathematical Operations
Combine or Split Arrays
Search, Sort, or Filter Arrays
Compute Aggregates and Statistics
Exit
